Research note

Model: implied value = TVL x 10^(3.31 - 0.53 x log10(TVL) + 0.47 x [infra]), fitted at run time from the snapshot's own 128 live tokens (n = 128, slope t = -5.5, infra t = 2.3), clamped to [0.02, 0.80]. [infra] is 1 for chains, exchanges, bridges, prediction markets, CeDeFi and governance-incentives protocols, else 0.

Infra: TVL is not the product for chains, exchanges, bridges, prediction markets, CeDeFi and governance-incentives protocols, so their TVL understates their footprint. Live infra tokens trade at a 2.94x premium at the same TVL (fitted +0.47 dex). The list is explicit in the model code.

Backtest: 5-fold cross-validation on the 128 live tokens gives median |log10 error| 0.48 (3.0x) for the infra model, against 0.56 (3.6x) for a single size curve and 0.72 (5.3x) for a flat median multiple; the infra model wins on all four fold assignments tried. Honest limit: residual SD 0.89 dex, so a typical error is still about 3.0x — the ranking is a comps estimate, not a prediction.

Rejected terms: growth and age were tested as regressors and carry no weight — fitted growth -1.6 (t = -1.6), fitted age -0.17 (t = -0.5); adding either hurts out-of-sample error (0.56-0.57 vs 0.47), so the shipped model carries neither as a multiplier. Growth's sign is negative because a 7-day TVL spike inflates the denominator before market cap reprices, so the observed ratio falls.

No pre-token discount is applied: the snapshot holds no pair from which one could be fitted, so any discount would be invented.

Exclusions: 145 pre-token protocols are off the board because they are wrapped, bridged, staked or exchange products of tokens that already trade, not protocols awaiting a token launch. Cross Chain Bridge joins them: Circle Gateway bridges USDC, a token that already trades.

Limits: the snapshot is frozen 2026-11-14. Multiples are comparables, not predictions, and no protocol name is hardcoded into the model.
